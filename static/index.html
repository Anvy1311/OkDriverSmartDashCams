DELIVERY NOTES · OPERATING MODEL

Architecture brief.

The prototype is a hybrid registry, unified viewing, analytics, and alert workflow.

Open API docs ↗
01

Registry first

Camera metadata is normalized into one auditable asset layer. The same registry powers health, GIS, routing, and adapter selection.

Read architecture ↗
02

Adapter-based feeds

RTSP and ONVIF are represented by separate adapters. Production adapters can exchange credentials at the gateway and return WebRTC/HLS.

Read integration notes ↗
03

Event-first alerts

Idempotent event ingestion validates source identity, stores inference metadata, correlates normalized identifiers, and broadcasts only after commit.

Read API workflow ↗

PATH TO 80,000 CAMERAS

Edge first, central intelligence second.

Regional gateways can normalize vendor protocols and run low-cost detection. Central services scale horizontally behind a queue, with PostgreSQL/PostGIS and object storage replacing the SQLite prototype store.
